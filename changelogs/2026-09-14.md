# 2026-09-14

## Moscow HTTPS proxy

- Added an authenticated HTTP CONNECT proxy over TLS using GOST v3.
- Added an nginx-only public frontend on Moscow and proxy egress on Helsinki.
- Reused the existing Cloudflare TCP transport because direct Moscow-to-Helsinki
  TCP is unavailable; the Helsinki proxy backend only binds to localhost.
- Added TLS/non-TLS stream multiplexing so the proxy and OpenVPN share the
  existing Cloudflare hostname without changing its published origin port.
- Added automatic one-time password generation and a Helsinki-only TLS key.
- Blocked direct proxy requests to common private and link-local networks.
- Added a publicly trusted, automatically renewed Let's Encrypt certificate for
  `proxy.nurshinov-vpn.com` and TLS re-encryption from nginx to Helsinki.
